# Visão Geral — moodle-block_recommendation

O **`moodle-block_recommendation`** é um plugin de bloco para a plataforma Moodle projetado para exibir blocos de conteúdos personalizados em HTML (avisos, banners, recomendações e links importantes) na página inicial do site ou no painel do usuário.

---

## 🚀 Principais Recursos

- **Editor Rich Text (HTML)**: Configuração de conteúdo dinâmico diretamente na interface do Moodle.
- **Locais de Exibição Estratégicos**: Otimizado para Página Inicial (`site-index`) e Dashboard (`my`).
- **Templates Mustache**: Renderização através de Mustache (`recommendation.mustache`) para conformidade visual.
- **Suporte Multi-idioma**: Tradução nativa para Português (pt_BR) e Inglês (en).
